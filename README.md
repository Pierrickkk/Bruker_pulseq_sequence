# Pulseq–Bruker Sequence Development & Testing

This repository was used during **2026** for the development, testing, and validation of MRI sequences for the **Pulseq–Bruker interpreter**, developed in:

https://github.com/PreclinicalPulseq/bruker_pulseq_private.git

The repository contains sequence developments, experiments, and **unit tests** used to validate the interpreter and its different functionalities.

Their corresponding **reconstruction** code are available on julia :

https://github.com/Pierrickkk/Reco_ERM.git

## Main development

The latest version of the **RARE-MRE sequence with the correct loop implementation** is:

`cleaned_rare_mre_pb`

This version should be considered the reference version for the RARE-MRE sequence developed during this work.

## Naming conventions

- `AT` → work or data provided by **Aurélien Trotier**
- `PB` → work or data provided by **Pierrick Bouilloux**

## Repository content

The repository includes:

- Pulseq sequence developments
- RARE / RARE-MRE sequences
- Unit tests for the Pulseq–Bruker interpreter
- Tests and examples for interpreter functionalities
- Experimental and intermediate developments from 2026

This repository primarily documents the development and testing work carried out during 2026.
